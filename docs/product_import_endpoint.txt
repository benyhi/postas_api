Feature:
Product import endpoint

Summary:
Added POST /api/v1/products/import/ for multipart CSV/XLSX/XLS product imports.
The endpoint validates file format, required columns, row values, duplicate conflicts,
tenant-scoped matches, and returns result, summary, items_loaded, matches, errors,
elapsed_ms, and eta_ms.

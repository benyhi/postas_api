Feature:
current tenant billing status endpoint

Summary:
Implemented a read-only frontend endpoint at GET /api/v1/billing/current-plan/.
The endpoint reads tenant_id from the authenticated JWT, calls postas_platform_api
through PlatformBillingClient.get_tenant_status, and returns the platform plan,
subscription, feature, limit, and usage payload without allowing writes.
